# AudioReplay

Мгновенный повтор для звука, как «Instant Replay» в видеодрайверах, только без видео и с разбивкой по приложениям.

- **Откат** — буфер последних N секунд хранится только в памяти. По хоткею сохраняются последние N секунд.
- **Непрерывная запись** — по другому хоткею звук пишется на диск, пока вы её не остановите.
- **Дорожка на приложение** — каждое приложение (Discord, игра, браузер…) записывается в отдельный WAV. Номер дорожки у приложения постоянный и не меняется между записями.
- **Без вмешательства в игры** — ничего не внедряется и не перехватывается, см. [docs/ANTICHEAT.md](docs/ANTICHEAT.md).

Работает на Windows 10 2004+ / Windows 11 (x64).

## Установка

Скачайте один из двух файлов (из [Releases](../../releases) или соберите сами):

| Файл | Размер | Когда брать |
|---|---|---|
| `AudioReplay.exe` | около 1 МБ | если на компьютере есть .NET 9 Desktop Runtime |
| `AudioReplay-standalone.exe` | около 46 МБ | если .NET нет и ставить его не хочется: всё уже внутри |

**Если .NET 9 не установлен**, `AudioReplay.exe` при запуске сам покажет окно с предложением скачать его. Можно поставить заранее:

- по ссылке: <https://dotnet.microsoft.com/download/dotnet/9.0> — раздел «.NET Desktop Runtime», вариант x64;
- или командой `winget install Microsoft.DotNet.DesktopRuntime.9`.

Установка не нужна: положите exe в любую папку и запустите.

## Быстрый старт

```powershell
.\scripts\publish.ps1          # соберёт dist\AudioReplay.exe и dist\AudioReplay-standalone.exe
.\dist\AudioReplay.exe         # запуск: значок появится в трее
```

| Действие | По умолчанию |
|---|---|
| Сохранить последние N секунд | `Alt+Q` |
| Начать / остановить запись | `Ctrl+Alt+Shift+Q` |
| Настройки | двойной щелчок по значку в трее, либо запустить `AudioReplay.exe` ещё раз |

Хоткеи, папка, длина отката, значок в трее и уведомления настраиваются в окне настроек (подробнее в [docs/USAGE.md](docs/USAGE.md)).

## Что получается на диске

```
Music\AudioReplay\
├─ 2026-11-07_14-30-12_replay_120s\     ← сохранённый откат
│   ├─ 02_discord.wav
│   ├─ 03_game.wav
│   ├─ 05_chrome.wav
│   └─ mix.wav                          ← один файл: все дорожки сложены вместе (по желанию)
└─ 2026-11-07_15-02-40_rec\             ← непрерывная запись
    └─ ...
```

Все файлы одной записи начинаются в один момент и имеют одинаковую длину, поэтому их можно просто перетащить в любой редактор (Audacity, Reaper, DaVinci…) — дорожки лягут синхронно. Число в имени файла — постоянный «слот» приложения (хранится в `%APPDATA%\AudioReplay\tracks.json`), так что `discord` всегда `02_discord.wav`.

## Структура проекта

```
AudioReplay/
├─ src/
│  ├─ AudioReplay.Core/   движок: захват, буферы, запись WAV, настройки (без UI)
│  └─ AudioReplay.App/    трей, хоткеи, окно настроек (WinForms)
├─ tests/AudioReplay.Tests/   юнит-тесты ядра (xUnit)
├─ docs/                  USAGE, ARCHITECTURE, ANTICHEAT
├─ scripts/               publish.ps1, smoke-test.ps1, make-icon.ps1
├─ assets/                иконка
└─ artifacts/, dist/      результаты сборки (не хранятся в git)
```

## Разработка

```powershell
dotnet build AudioReplay.sln
dotnet test                                    # юнит-тесты
.\scripts\smoke-test.ps1                       # сквозная проверка на реальном звуковом устройстве
```

Команды для уже запущенного экземпляра (удобно для Stream Deck и скриптов):
`AudioReplay.exe --save`, `--record`, `--settings`, `--exit`.

> Папка проекта лежит в Nextcloud: `artifacts/` и `dist/` лучше добавить в игнорируемые, чтобы не синхронизировать результаты сборки.
