# Совместимость с античитами

Цель: приложение не должно делать ничего, что античит способен принять за вмешательство в игру. Поэтому оно ограничено тем, что Windows даёт обычным приложениям штатно.

## Чего приложение НЕ делает

- Не внедряет DLL и не пишет в чужую память.
- Не ставит хуки: ни `SetWindowsHookEx`, ни перехват клавиатуры и мыши, ни хуки API.
- Не рисует оверлей поверх игры и не лезет в графику.
- Не ставит драйверов и не использует виртуальных аудиоустройств: ни Virtual Audio Cable, ни VoiceMeeter не нужны.
- **Не открывает дескриптор процесса игры** — ни `OpenProcess`, ни `Process.GetProcessById`, ни `MainModule`.
- Не требует прав администратора и не запускает служб.

## Что делает

| Задача | Используемый механизм |
|---|---|
| Узнать, какие приложения играют звук | Публичный API сессий звука (`IAudioSessionManager2`): получает только PID и состояние |
| Узнать имя exe по PID | `CreateToolhelp32Snapshot`: снимок списка процессов **без открытия дескрипторов** процессов |
| Захватить звук приложения | Штатный режим WASAPI *process loopback* (Windows 10 2004+). Приложение называет PID, а звук выдаёт аудиосервис Windows |
| Глобальные хоткеи | `RegisterHotKey`: получает только те сочетания, которые вы сами зарегистрировали. Нажатия остальных клавиш не видит |
| Запись на диск | Обычные файловые операции в вашей папке |

Всё это те же вызовы, что используют диктофоны, OBS и Discord.

## Честные оговорки

1. **Реальные античиты не проверялись.** Тесты шли на системных звуках, без запуска игр с Vanguard, EasyAntiCheat, BattlEye и подобными. Выше описан дизайн, а не результат испытаний на конкретной игре.
2. **Приложение не подписано.** Некоторые античиты и SmartScreen относятся с подозрением к неподписанным exe. Если нужно, подпишите `dist\AudioReplay.exe` своим сертификатом.
3. **Режим self-contained** упаковывает среду .NET в exe и увеличивает его до десятков мегабайт. Если вы хотите минимум постороннего кода, лучше собирать обычный framework-dependent вариант.
4. **Запрет на захват.** Если для конкретной игры хочется исключить любое взаимодействие, добавьте её exe в «Не записывать приложения»: тогда программа не будет запрашивать захват её звука вообще. Её звук при этом не попадёт и в общий микс.
5. **Правила игр могут отличаться.** Если риск бана для вас критичен (соревновательные игры с kernel-античитом), сначала проверьте правила и FAQ конкретной игры либо попробуйте на второстепенном аккаунте.
