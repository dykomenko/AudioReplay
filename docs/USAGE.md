# Использование

## Режимы

**Буфер отката** (включён по умолчанию). Приложение постоянно держит в оперативной памяти последние N секунд звука каждого приложения. На диск ничего не пишется, пока вы не нажмёте хоткей отката. Тишина в памяти не занимает места: в буфере хранятся только фрагменты со звуком.

**Непрерывная запись.** Хоткей запуска/остановки пишет звук на диск в реальном времени. Запись и буфер работают независимо, можно включать их вместе. Если буфер отключён, а запись идёт, захват работает только на время записи.

Длинная запись автоматически делится на части (по умолчанию каждые 180 минут: ограничение формата WAV — 4 ГБ). Части лежат в папках `…_rec`, `…_rec_part2`, …

## Окно настроек

Открывается двойным щелчком по значку в трее или повторным запуском `AudioReplay.exe` (это единственный способ попасть в настройки, когда значок скрыт).

| Параметр | Что делает |
|---|---|
| Папка для записей | Куда сохраняются клипы и записи |
| Держать буфер отката | Выключите, если нужна только непрерывная запись |
| Длина отката | 5–900 секунд. Расход памяти: около 0,2 МБ на секунду на каждое приложение со звуком |
| Хоткеи | Щёлкните в поле и нажмите сочетание. Пока открыто окно настроек, хоткеи приложения отключены, поэтому сочетание можно переназначить |
| Микрофон | Отдельная дорожка `01_microphone.wav`. Выключено по умолчанию |
| Общий микс | Дополнительно пишет `mix.wav` — сумму всех дорожек |
| Значок в трее | Можно скрыть. Приложение продолжит работать, а хоткеи и уведомления останутся |
| Уведомления | Всплывающее сообщение о сохранении. Если значок в трее скрыт, он показывается на несколько секунд только на время уведомления. Щелчок по уведомлению открывает папку |
| Запускать вместе с Windows | Добавляет запись в `HKCU\...\Run` (права администратора не нужны) |
| Не записывать приложения | Список имён exe, которые никогда не захватываются |

Все настройки лежат в `%APPDATA%\AudioReplay\settings.json`. Лог — в `audioreplay.log` рядом.

## Дорожки и их порядок

Каждое приложение определяется по имени exe (`chrome`, `discord`, …). При первой встрече ему выдаётся постоянный номер, и он больше никогда не меняется и не переиспользуется. Файл `tracks.json` можно править вручную, если хочется другой порядок. Микрофон всегда занимает слот 1.

Один и тот же exe с несколькими процессами (например, Chrome) объединяется в одну дорожку.

## Командная строка (для запущенного экземпляра)

```
AudioReplay.exe --save        сохранить откат
AudioReplay.exe --record      начать/остановить запись
AudioReplay.exe --settings    открыть настройки
AudioReplay.exe --exit        завершить приложение
```

## Ограничения

- Новое приложение начинает записываться в течение примерно секунды после того, как заиграл звук: именно столько занимает опрос списка звуковых сессий. Самая первая доля секунды звука нового приложения может не попасть в запись.
- Формат фиксированный: WAV, 48 кГц, 16 бит, стерео.
- Захват по приложениям требует Windows 10 2004 или новее.
- Если родительский процесс и его дочерний процесс другого exe играют одновременно (например, лаунчер и игра), звук игры может попасть и в дорожку лаунчера: так работает захват дерева процессов в Windows.
